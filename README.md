# Medical Resource Foundation Website

A modern React + Tailwind CSS website for the Medical Resource Foundation, providing disability resources, waiver advocacy, autism coaching, and medical equipment assistance in Dayton, Ohio.

## 🚀 Project Features

- **React 18** - Modern UI library with hooks
- **Tailwind CSS** - Utility-first CSS framework
- **Vite** - Lightning-fast build tool
- **Responsive Design** - Mobile-first approach
- **SEO Optimized** - Semantic HTML, meta tags, keywords
- **Accessibility** - ARIA labels and semantic elements

## 📁 Project Structure

```
medical-resource-foundation/
├── src/
│   ├── App.jsx           # Main React component
│   ├── index.js          # React entry point
│   └── index.css         # Global styles with Tailwind
├── index.html            # HTML entry point
├── package.json          # Dependencies and scripts
├── vite.config.js        # Vite configuration
├── tailwind.config.js    # Tailwind configuration
├── postcss.config.js     # PostCSS configuration
├── .gitignore            # Git ignore file

```

## 📦 Installation

### Prerequisites
- Node.js 14+ and npm

### Setup

1. Clone the repository:
```bash
git clone https://github.com/anewhadden1/Medical-Resource-Foundation.git
cd Medical-Resource-Foundation
```

2. Install dependencies:
```bash
npm install
```

## 🏃 Development

Start the development server:
```bash
npm run dev
```

The site will open in your browser at `http://localhost:3000` with hot reload enabled.

## 🏗️ Build

Build for production:
```bash
npm run build
```

This creates an optimized build in the `dist/` directory.

## 👀 Preview

Preview the production build:
```bash
npm run preview
```
